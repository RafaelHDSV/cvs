# Currículos

Pasta com o currículo em HTML/PDF, otimizado para ATS e vagas de desenvolvimento.

## Arquivos

| Arquivo | Uso |
|---------|-----|
| `Currículo.html` | Versão principal (PT) — edite aqui |
| `Currículo.pdf` | Envio em candidaturas (gerado a partir do HTML) |
| `Resume.html` | Versão em inglês — edite aqui |
| `Resume.pdf` | English CV for applications (from Resume.html) |
| `Resume.docx` | English CV in Word format |
| `analise-ats.md` | Checklist e notas sobre compatibilidade com ATS |
| `Currículo_2025.html` | Histórico — não alterar |

## Como atualizar

1. Edite `Currículo.html` no navegador ou no editor.
2. Exporte para PDF: abra o HTML no Chrome/Edge → **Ctrl+P** → Salvar como PDF.
3. Confirme que o PDF permite **buscar texto** (Ctrl+F). Se não permitir, reexporte.
4. Substitua `Currículo.pdf` e, se quiser, revise `analise-ats.md`.

## Dica

Mantenha **1 página** e caracteres simples (`|`, `-`) nos separadores para parsers de ATS.
